# Stalca Administradora de Condomínios

Site institucional moderno, responsivo e otimizado desenvolvido para a **Stalca Administradora de Condomínios**, empresa com atuação tradicional em Curitiba e no litoral paranaense desde 1989.

---

## 🚀 Sobre o Projeto

Este projeto tem como objetivo principal apresentar os serviços prestados pela administradora (gestão financeira, recursos humanos e operações), além de oferecer canais diretos de contato via WhatsApp, e-mail e uma seção interativa de **Perguntas Frequentes (FAQ)** em formato accordion.

### ✨ Principais Funcionalidades
* **Design Responsivo:** Adaptado perfeitamente para dispositivos móveis, tablets e desktops (Mobile First / Flexbox & Grid).
* **FAQ em Formato Accordion:** Perguntas frequentes interativas com animações suaves de expansão e recolhimento.
* **Mapa Integrado:** Localização exata da sede (Praça Zacarias, Curitiba - PR) via Google Maps com coordenadas otimizadas.
* **Acesso Direto ao SGConline:** Atalho rápido para o sistema de gestão dos condôminos.
* **Canais de Atendimento Setorizados:** E-mails específicos para cada departamento (Boletos, Contas a Pagar, RH, etc.) e link direto para atendimento comercial no WhatsApp.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Semântico)
* **CSS3** (Variáveis CSS, Flexbox, CSS Grid, Responsividade)
* **JavaScript** (Manipulação do DOM para o Accordion interativo)
* **Google Fonts** (Plus Jakarta Sans)
